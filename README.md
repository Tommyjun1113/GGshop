# GGshop

GGshop 是一款使用 Kotlin 與 Android Studio 開發的 Android 行動商店應用程式，
搭配 Firebase 作為後端服務，實作 Android 與 Web 共用的電商系統，
涵蓋自訂使用者驗證、購物流程、優惠券機制與訂單管理，
模擬實際商用電商 App 的使用情境。

---

## 開發環境與技術
- Kotlin
- Android Studio
- Android SDK
- RecyclerView
- Activity / Fragment
- Intent
- MVVM 架構
- Git / GitHub
- Firebase Firestore
- 第三方服務：SendGrid

---

## 後端與跨平台架構（Firebase）
- 使用 Firebase 作為後端服務，集中管理使用者、商品、購物車、訂單與優惠券資料
- Android 與 Web 端共用同一套 Firebase 後端，實現跨平台資料讀寫
- 透過 Firebase Firestore Snapshot Listener 實作即時資料同步，確保不同平台間資料一致性
- 自行設計使用者驗證流程，並透過 Firebase 管理使用者登入狀態與相關資料
- 規劃資料結構與存取規則，確保資料安全性與系統可維護性
  
---

## 專案架構設計
- 採用功能導向（Feature-based）的 Package 結構，依功能模組劃分 UI
- 各功能模組內實作 MVVM 架構，將畫面、邏輯與資料來源分離
- Adapter、ViewModel 與資料模型職責清楚，提升專案可維護性與擴充性

---

## 使用者驗證與權限控管
- 未登入使用者可瀏覽商品頁面，但無法進行購物相關操作
- 使用者需完成登入後，才能使用搜尋、購物車、最愛與購買功能
- 實作使用者註冊、登入與登出流程
- 支援忘記密碼流程，需完成驗證後才能重新設定密碼

---

## 自訂 Email 驗證與密碼重設機制
- 自行設計 Email 驗證流程，系統產生隨機驗證碼並儲存於 Firebase
- 透過後端 API 串接 SendGrid 發送驗證碼，避免敏感金鑰暴露於前端
- 使用者需完成驗證碼驗證後，才能進行註冊或密碼重設
- 實作驗證碼重送限制與倒數計時機制，避免短時間內重複發送
- 驗證成功後，透過 Firebase Firestore 更新使用者資料狀態
> SendGrid API 金鑰以安全方式管理，未直接寫入程式碼中

## 商品與購物功能
- 商品列表與商品詳細頁面顯示
- 商品搜尋功能
- 加入最愛商品管理（即時同步）
- 加入購物車與直接購買功能
- 即時顯示購物車內商品數量

---

## 優惠券與推薦機制
- 自動判斷並套用最適合的優惠券
- 當購買金額未達優惠門檻時，自動推薦三項最接近門檻金額的商品供使用者補差價
- 優惠券狀態管理：未使用 / 已使用 / 已過期
- 通知頁面顯示各類優惠券狀態

---

## 訂單與交易管理
- 顯示使用者完整購買紀錄
- 提供訂單明細資訊，包含：
  - 付款方式
  - 購買時間
  - 商品名稱
  - 訂單狀態
  - 使用的優惠券
  - 訂單總金額
- 提供退貨功能，並管理訂單狀態流轉

---

## 個人帳戶管理
- 顯示並管理使用者個人資料
- 支援使用者自行編輯與更新個人資訊
- 我的最愛清單顯示（即時同步）
- 提供刪除帳戶功能，並同步清除使用者相關資料
- 提供登出功能

---

## 聯絡我們
- 提供聯絡電話，支援點擊後直接撥打
- 提供 Email 聯絡方式，可直接開啟信箱填寫意見回饋

---

## 專案學習重點
- 自行設計完整的使用者驗證與權限控管流程
- 使用 Firebase 建立跨平台（Android / Web）共用後端架構
- 使用 Firestore Snapshot Listener 實作即時資料同步機制
- 整合第三方服務（SendGrid）實作 Email 驗證與密碼重設流程
- 實作購物、優惠券與訂單狀態管理邏輯
- 使用 MVVM 架構提升程式碼可維護性與擴充性
- 培養良好的狀態管理、除錯與官方文件查閱能力
